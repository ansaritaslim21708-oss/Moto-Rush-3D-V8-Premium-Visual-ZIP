HOW TO PLAY

⌨️ Keyboard: A/D or ←/→ to steer, Space to boost, P to pause.

📱 Mobile: use the on-screen buttons.

💰 Collect coins. Avoid traffic and obstacles. Nitro gives a speed burst.

🏁 Levels use the requested duration: 1=1 min, 2=2 min, 3=3 min, 4=5 min, 5=7 min. Later levels become progressively longer.

ABOUT THE PROJECT

Moto Rush 3D is a self-contained first-year academic web game. It demonstrates HTML, CSS, JavaScript, Canvas rendering, game loop, collision detection, levels, scoring, localStorage, keyboard/touch input and Web Audio. No external 3D library or CDN is required.
